# Чек-лист для чат-бота «Личный помощник»

В файле **`faq-checklist.json`** перечислены типичные вопросы, которые задают люди. Ваша задача — заполнить поле **`answer`** в каждом блоке (одним ответом на все варианты вопросов в блоке).

## Как заполнять

1. Откройте `faq-checklist.json` в редакторе.
2. В каждом объекте есть массив **`questions`** (как люди могут спросить) и строка **`answer`** (ваш ответ).
3. Напишите ответ в **`answer`**. Один раз на блок — он будет использоваться для всех вариантов вопросов в этом блоке.
4. Если ответа пока нет — оставьте `"answer": ""`. Тогда бот будет отвечать: «Уточняйте по контактам на сайте».

## Пример

Было:
```json
{
  "questions": ["В каких городах проводятся группы?", "В каком регионе проходят интенсивы?"],
  "answer": ""
}
```

Стало:
```json
{
  "questions": ["В каких городах проводятся группы?", "В каком регионе проходят интенсивы?"],
  "answer": "Группы и интенсивы проходят в Москве, Санкт-Петербурге, Сочи, а также выездные программы в Европе и Азии. Конкретные города и даты — в расписании, напишите в Telegram или WhatsApp."
}
```

## После заполнения

Из папки проекта выполните:

```bash
node scripts/merge-faq-into-knowledge.js
```

Скрипт добавит ваши ответы в `knowledge.json`, и чат-бот начнёт ими пользоваться. Можно запускать скрипт после каждого обновления чек-листа.

## Что в чек-листе

| Тема | Что писать в answer |
|------|----------------------|
| Города / регион | В каких городах и странах проходят группы и интенсивы |
| Расписание групп | Ближайшие даты или как часто проходят группы |
| Расписание Праймал | Даты или регулярность Праймал и мужских групп |
| Расписание пятидневных | Когда планируются 5-дневные интенсивы |
| Проживание | Входит ли в цену, сколько стоит отдельно, что включено |
| Что взять с собой | Список вещей, документы, рекомендации |
| Скидки / предоплата | Условия скидок, предоплаты |
| Как добраться / адрес | Адрес или описание места, как доехать |

Можно добавлять в `faq-checklist.json` свои блоки по тому же формату (`"questions": [...], "answer": "..."`), затем снова запускать скрипт.
